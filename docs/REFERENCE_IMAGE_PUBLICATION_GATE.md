# Gate di pubblicazione dei riferimenti immagine

Il repository Design-App è **pubblico** e contiene opere di terzi con copyright non necessariamente verificato. Gli upload dell'utente (35 file, 33 immagini distinte) sono stati analizzati e catalogati, **non redistribuiti**. Anche watermark, nomi commerciali, marchi e grafiche riconoscibili restano solo nella galleria privata.

Per pubblicare ogni JPG in `IMMAGINI/`, registrare:
1. autore e URL dell'opera e licenza/permesso di redistribuzione;
2. prova archiviata e attribuzione;
3. autorizzazione per pubblicazione nel repository pubblico (non basta «saved on Pinterest» o «free» sulla miniatura);
4. SHA-256 e ID stabile per evitare duplicati;
5. eventuale redazione di loghi o elementi non autorizzati;
6. PR, review e verifica dei gate del repository.

Solo dopo il controllo dei diritti si può passare da `LOCAL_ONLY` a `REPO_PUBLISHED` e valorizzare i percorsi reali nel catalogo. Un'alternativa resta usare una galleria privata, senza GitHub pubblico.

Il riferimento visivo può ispirare un design autonomo e originale; non equivale a copiare pixel, loghi o asset. Le scelte di design nelle app richiedono approvazione e QA.
