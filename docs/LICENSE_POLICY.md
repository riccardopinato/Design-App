# Design-App licensing and provenance

Design-App is a public repository. First-party code and app design assets
are not accompanied by a blanket open-source license. The repo owner
retains the applicable rights and will decide separately whether to grant
any broad external redistribution rights.

Source snapshots preserve the license/ownership of their donor app.
The six upstream interface WAV files under the Semantic Sound Pack are CC0,
with exact per-asset source paths and license copies in that pack.
Material Icons are an upstream Apache-2.0 ecosystem dependency, not
assets copied into this repository. audioplayers is MIT-licensed.

Internal App Factory reuse must respect the donor, Product Bible, pinned
source version and any included third-party asset licenses. Public
availability of a reference library is not a license to redistribute
external copyrighted code.
