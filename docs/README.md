# Galleria HTML Design-App · UIR Lightbox

Questa directory contiene [index.html](./index.html): un visualizzatore statico in italiano, senza dipendenze, con 99 riferimenti (`UIR-0001…UIR-0101` esclusi due duplicati), ricerca testuale, filtri per app, stile e provenienza, lightbox fullscreen, frecce tastiera, chiusura con ESC e link direttamente condivisibili tramite hash (`#UIR-0036`).

## Pubblicazione su GitHub Pages (una sola volta)

GitHub non permette di eseguire JavaScript nella vista Markdown/file `blob`. Per usare la sovrimpressione sul web:

1. Apri le [impostazioni Pages di Design-App](https://github.com/riccardopinato/Design-App/settings/pages).
2. Seleziona **Deploy from a branch** come fonte, branch **main**, cartella **/docs**, poi **Save**.
3. Al termine del deploy, la galleria dovrebbe trovarsi all'indirizzo `https://riccardopinato.github.io/Design-App/` (verificare l'URL effettivo in Settings → Pages).
4. Esempio di deep-link: `https://riccardopinato.github.io/Design-App/#UIR-0036`.

**Alternativa già disponibile senza Pages:** [Anteprime GitHub](../UI-UX/ANTEPRIME_99.md) ha un pannello espandibile per ogni UIR. I link nelle tabelle aprono direttamente il JPEG associato.
