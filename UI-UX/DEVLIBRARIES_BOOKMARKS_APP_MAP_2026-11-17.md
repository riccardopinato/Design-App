## Applicabilità prioritaria

- **Anna’s Diary:** Skeleton/Apple Breathe/Pulsating Dots per contenuti realmente in attesa; Notification List rimane la proposta non implementata di riepilogo reale degli appuntamenti in Home Oggi; Face Id Scan **solo feedback biometrico di API già riuscita**, mai simulare sicurezza.
- **Omni Cleaner:** scansioni/analisi con loader poco costosi; mai mostrare progressi falsi o peggiorare frame rate della galleria/video.
- **Notes-Ecosistema:** Skeleton per liste di note, sync con indicatore controllato da stato reale, niente distrazioni sul canvas.
- **World Days:** Skeleton per schede/storie, spinner breve solo quando dati non disponibili; palette invariata.
- **Cooking Anime:** Morph Loader o Bouncing Lines solo con attesa reale e coerenti con stile kawaii, senza sovraccaricare la Home.
- **Wonderlog / TrailPath / CamperBoss:** View On Map solo come idea di preview, non sostituto delle mappe/route/offline già definite.

**Nota:** questa matrice mostra compatibilità **proposta**, non presenza della feature nel codice, validazione dell'animazione o licenza di ogni file.
