## UID workflow
The permanent UID registry maps human-friendly \`UID-xxxx\` to original IDs without changing them. Example: \`UID-0127\` resolves to \`RXN-button-copy\`; \`UID-0350\` to \`RXN-verification-input\`. A phrase \`Usa UID-0127 per [ruolo] nell'app [prodotto]\` should resolve ID, code/preview/rights, app stack, a short adaptation plan and regression gates. No automatic native code copying from incompatible original source, unlicensed assets or approval-free app redesign.

## Source-quality gates
- \`SOURCE_ARCHIVED\` = exact code exists in Design-App, NOT tested adaptation.
- \`PREVIEW_CAPTURED_UNREVIEWED\` = real image evidence, NOT pixel-perfect visual approval.
- \`LIBRARY_VERIFIED/COPY_READY\` requires native adapter/package decision, tests and source-matched visual QA.
- \`CONSUMER_VERIFIED\` requires target app test and physical/provider checks where pertinent.
- New source additions must append UID (not reorder historical UID), preserve aliases and regenerate all derived table views; CI checks SHA, filenames, schema and counts.

No fake source/photo, implicit Golden promotion, consumer app edits or blanket UI package installation in this audit.
