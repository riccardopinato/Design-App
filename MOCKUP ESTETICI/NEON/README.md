# NEON — Neon

**ID:** `MOCK-STYLE-002` · **Stato:** REFERENCE / categorizzazione preliminare · **Immagini:** 0

Superfici scure con accenti luminosi, bagliori contenuti e gerarchia ad alto contrasto. L'effetto non deve compromettere leggibilità, autonomia o sicurezza.

**Palette orientativa:** Grafite, nero, ciano, viola, verde elettrico.
